# Research: Web Config Editor & Desktop UX Fixes

**Feature**: `007-web-config-desktop-ux` | **Date**: 2026-05-22

## 1. Editable config via existing API

**Decision**: Use `PATCH /config` only; no new write routes.

**Rationale**: 005 already exposes `com_port`, `baud`, `udp_listen_host`, `udp_listen_port`, `network_mode` in OpenAPI; discovery row select already patches COM.

**Gap**: `app_facade._apply_config_on_main` ignores `network_mode` today — must map to Qt radios.

**Alternatives considered**: New `/config/form` POST — rejected (duplicate contract).

---

## 2. QR token delivery

**Decision**: `GET /token-qr` returns **SVG** generated by pure Python (`web/qr_svg.py`, Nayuki-style or minimal byte-mode QR). Payload = raw token string from `ui_prefs` `web_ui.token`. Dashboard uses `<img src="/token-qr?t=...">` or inline SVG fetch when checkbox enabled.

**Rationale**: Spec requires offline; avoids new pip dependency; phone scans monitor showing PC browser dashboard.

**Alternatives considered**:
- CDN `qrcode.js` — rejected (offline rule).
- `pip install qrcode` — rejected for mandatory dep (optional later).
- QR on desktop Qt only — deferred; web route covers “show on PC screen for phone scan”.

---

## 3. Field Guide clipping

**Decision**: Wrap Guide tab content in `QScrollArea` with `setWidgetResizable(True)`; set `QFormLayout.setVerticalSpacing(8)` and `setFieldGrowthPolicy(ExpandingFieldsGrow)` on web form; `web_box.setMinimumHeight(220)`.

**Rationale**: Screenshot shows clipped form rows in cramped Field drawer; scroll is consistent with UI polish rule.

**Alternatives considered**: Increase `drawer_tabs` min height only — insufficient when window short.

---

## 4. Standard COM dropdown

**Decision**: Fix `refresh_ports` to save/restore `currentText()`; use `QComboBox.InsertPolicy.NoInsert` after populate; call `refresh_ports` from `_finalize_ui` if list empty.

**Rationale**: `clear()` drops selection; empty list at launch matches “broken” report.

**Alternatives considered**: Replace with hub-only picker — rejected (Standard still uses COM row).

---

## 5. Standard Connect resize

**Decision**: Verify existing `connect_panels.py` vertical splitter; fix if `OpaqueResize` false or scroll area steals drag. Ensure `reset_sizes` on toolbar resets splitter + panel heights.

**Rationale**: Infrastructure already exists per layout rule; likely regression or handle visibility, not greenfield.

---

## 6. Running guard UX

**Decision**: Dashboard disables config inputs when `status.running`; Save hidden; show lock banner referencing Stop.

**Rationale**: Matches 005 façade `running_guard` without new API.
